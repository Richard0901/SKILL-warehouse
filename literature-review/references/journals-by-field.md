## Using This Reference

When analyzing a new field:

1. Identify the field category above
2. Note top-tier journals for quality filtering
3. Consider journal-specific preferences (clinical vs basic)
4. Use IF as rough quality indicator (not absolute)

For fields not listed, search for:
- "[Field] top journals impact factor"
- Society flagship journals (e.g., AHA, ASCO, ESMO)
- Lancet specialty journals
- Nature Reviews journals
